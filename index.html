近光灯

有路灯照明的道路行驶能看清路况就用近光
近距离跟车行驶避免晃到前车
通过有信号灯控制的路口
无路灯照明，且对向车道150米内有车只要提到「对向有车」就用近光

远光灯

在无路灯照明的道路上行驶没提「对向有车」才能用远光

远近光灯交替 3 下

夜间通过拱桥
夜间通过人行横道
夜间通过无信号灯路口
夜间通过急弯

转向灯

路口左转弯 → 开启左转向灯超车除外，见下
超车 → 左转向灯 + 远近光交替3下两步缺一不可

雾灯 + 双闪

雾天行驶 → 雾灯 + 双闪开远光会形成光幕，反而看不清
大雨中行驶 → 雾灯 + 双闪
临时停车 → 大灯关一档 + 双闪不是关灯，留示廓灯
